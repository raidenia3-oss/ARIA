# Núcleo Visual ARIA

Estructura mínima y no intrusiva. Objetivo: sobreponerse de forma pequeña para pasar desapercibida,
pudiendo observar lo que sucede en pantalla y actividad, con capacidad de distinguir identidad
y contexto sin inventar datos.
