## Session Management Patterns (from Pi Agent)
```python
# Each chat session gets episodic context
session_id = req.session_id or str(int(time.time() * 1000))

# Retrieve relevant memories before generating response
mem_result = await retrieve_memory(query=text, top_k=3, mode="associative")
if mem_result.results:
    context = "\n\nContexto episódico:\n" + "\n".join(
        f"- {item['node']['content']['summary']}"
        for item in mem_result.results
    )
    system_prompt += context

# Store conversation after response
await store_memory(query=text, response=response_text)
```

## Pi Agent Skills Integration
```python
# Map skills to LongMemory facets
SKILL_FACETS = {

# Store with facet hint
await store_memory(query, response, facet_hint=SKILL_FACETS[skill])
```
