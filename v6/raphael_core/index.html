    02 — Nucleo / telemetria medida
    
          
    Lo que el nucleo sabe de verdad
    
          
    
            Cada fila es una sonda HTTP real contra el backend de ARIA. Si una
            sonda no responde, la fila lo dice: no hay numeros inventados ni
            ceros de relleno.
          
    

          
    

          
    
            
            
          
    
          
    
            Esta pagina es estatica: el navegador llama al backend desde tu
            maquina, asi que hace falta CORS. Sin el, las sondas devuelven
            unavailable y el HUD lo
            muestra tal cual. Anade el origen del sitio a
            AURA_CORS_ORIGINS (lista separada por comas) para que
            respondan.
          
    
          
    
            Ultima lectura: sin lectura
          
    
        
    
      
    

      
      
    
        
    
          
    03 — Raphael / sub-skills
    
          
    Las seis que mueven el nucleo
    
          
    
            La wiki de Tensura lista exactamente seis sub-skills para Raphael.
            Cada una dibuja una pieza concreta del nucleo y su lectura sale de
            las sondas reales, no de una animacion.
          
    

          
    

          
    
            Material de referencia de fan: los nombres, el kanji y la cadena
            evolutiva salen de la wiki de
            That Time I Got Reincarnated as a Slime. No dicen nada de
            ARIA. Lo que si es de ARIA es la lectura de cada tarjeta.
          
    
        
    
      
    

      
      
    
        
    
          
    04 — Element cores / acceso
    
          
    Seis nucleos, seis subsistemas
    
          
    
            La arquitectura de Raphael translated a ARIA: cada elemento es un
            subsistema real y su color en orbita es su estado real.
          
    
          
    
        
    
      
    

      
      
    
        
    
          
    05 — Acceso / arranque
    
          
    Como encender el nucleo
    
          
    
            Comandos verificados del repositorio. Pulsa cualquier bloque para
            copiarlo.
          
    

          
    
            
    Paso 01 — Lanzador de escritorio
    
            
    .\aura-os\scripts\start-aura-app.ps1 -Exe
    
          
    

          
    
            
    Paso 02 — Modo standalone (sin servidor)
    
            
    .venv\Scripts\python.exe AURA_APP\aria_main.py
    
          
    

          
    
            
    Paso 03 — Stack v5 (Electron + React)
    
            
    cd v5
npm install
npm run dev
    
          
    

          
    
            
    Paso 04 — Comprobar el backend
    
            
    curl.exe -s http://localhost:8000/health
curl.exe -s http://localhost:8000/api/swarm/roles
    
          
    

          
    
            
    Paso 05 — Abrir este HUD contra el backend
    
            
    http://localhost:8000/?api=http://localhost:8000
