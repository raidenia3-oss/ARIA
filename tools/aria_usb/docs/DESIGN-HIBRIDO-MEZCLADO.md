# DISEÑO MEZCLADO: Híbrido + Móvil (Termux + Grok Bot local) + Motor unificado modular
## Objetivo
Mezclar ambas ideas:
- Versión híbrida: todo-en-uno + módulos separados
- Semi-asíncrono: que avance sin usuario cuando PC apagada (Termux Android) y se comunique con móvil (AIRIS) para pedir aprobaciones/dudas
- Entrenamiento + des-censura automatizables, local-first
