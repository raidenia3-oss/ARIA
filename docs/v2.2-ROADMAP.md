# AURA OS v2.2 Roadmap

Planned features and improvements for v2.2 (Q4 2026).

## High Priority

### 1. GraphQL API
- [ ] GraphQL schema for all 117 routes
- [ ] Query optimization with DataLoader
- [ ] Subscriptions for real-time updates
- [ ] Migration guide from REST

**Rationale**: Reduce over-fetching, better dev experience, leverage existing data structures

**ETA**: 3 weeks

### 2. Advanced Task Scheduler
- [ ] Cron-based scheduling
- [ ] Recurring tasks with conditions
- [ ] Task dependencies (DAG execution)
- [ ] Backoff & retry strategies
- [ ] Integration with Celery/RQ

**Rationale**: Automate complex workflows, enterprise requirement

**ETA**: 4 weeks

### 3. Local Model Support (vLLM/Ollama)
- [ ] Integrate vLLM for inference
- [ ] Ollama model management
- [ ] Hugging Face Model Hub integration
- [ ] Fallback to local models if providers down
- [ ] Quantized model support (GGUF, AWQ)

**Rationale**: Privacy-first option, cost reduction, offline capability

**ETA**: 3 weeks

### 4. Kubernetes Operator
- [ ] AURA CRD (Custom Resource Definition)
- [ ] Helm charts for deployment
- [ ] StatefulSet for HA
- [ ] Auto-scaling based on metrics
- [ ] PVC for persistent data

**Rationale**: Enterprise Kubernetes adoption, cloud-native

**ETA**: 6 weeks
