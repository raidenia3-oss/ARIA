# AURA Ambxst Theme & Background Customizer
Extiende temas con "ambxst-dark" y "ambxst-light", permite fondo personalizado (gradiente/imagen URL).

Comandos sugeridos desde ARIA:
- theme:set ambxst-dark / theme:set ambxst-light
- background:set url("https://.../img.jpg")
- background:set linear-gradient(135deg, #7e5aa0 0%, #5f86c9 100%)
- background:clear
